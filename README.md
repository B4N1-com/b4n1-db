# b4n1-db — Public Mirror

This repository is the **public mirror** (vitrina) of the `b4n1-db` SDK.
It contains SDKs, prebuilt binaries, documentation and legal files only.

**Source code stays private** (§10h). No Rust source, no `Cargo.toml`,
no build scripts, no secrets are published here.

## Install

```bash
pip install b4n1-db          # Python
npm install b4n1-db         # Node.js
dotnet add package B4n1.Db  # .NET
gem install b4n1-db         # Ruby
```

See the full documentation inside each SDK directory.
